# 지역·상품 카테고리별 매출 현황

매장 관리자가 **지역·상품 카테고리·기간**을 선택해 매출 실적과 추이를 확인하는 Streamlit 앱입니다.
데이터 기준은 2026년 1~10월(`sales_sample.csv`)입니다.

## 주요 기능

- **사이드바 필터 (조건 선택)**
  - 지역: 여러 개 선택. 처음에는 전체가 선택되어 있습니다.
  - 상품 카테고리: 드롭다운. '전체'를 포함합니다.
  - 기간: 시작일과 종료일을 고르는 날짜 범위 슬라이더
  - 필터 아래에 `선택 조건: N건 / 전체 M건`을 표시합니다.
- **요약 탭**
  - 숫자 카드: 총매출, 주문 건수, 평균 주문액
  - 월별 매출 합계 그래프: 두 달 이상이면 선 그래프, 한 달이면 막대그래프
  - 지역별 매출 합계 막대그래프: 매출이 큰 순서
- **상세 데이터 탭**: 조건에 맞는 데이터 전체를 표로 보여 줍니다.
- **안내 메시지**
  - 조건에 맞는 데이터가 0건이면 안내 문구만 보여 주고, 카드·그래프·표는 그리지 않습니다.
  - CSV 파일이 없으면 파일 이름과 위치를 확인하라고 안내하고 멈춥니다.
  - 필수 열(date, region, category, sales, quantity)이 빠져 있으면 빠진 열 이름을 알려 주고 멈춥니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `app.py` | 앱 화면 코드 |
| `sales_sample.csv` | 매출 데이터. 열: date, region, category, sales, quantity |
| `requirements.txt` | 필요한 라이브러리와 버전 |

## 실행 방법

1. 라이브러리를 설치합니다.

   ```bash
   pip install -r requirements.txt
   ```

2. 프로젝트 폴더에서 앱을 실행합니다.

   ```bash
   streamlit run app.py
   ```

3. 브라우저에서 `http://localhost:8501`이 열립니다.

> `app.py`는 같은 폴더의 `sales_sample.csv`를 읽습니다. 반드시 프로젝트 폴더 안에서 실행하세요.

## 확인 방법: 지역을 모두 해제하면 0건

1. 앱을 실행합니다.
2. 왼쪽 사이드바의 **지역** 선택 상자에서 선택된 지역을 모두 지웁니다(각 지역 옆의 ×를 누릅니다).
3. 다음 결과가 나오면 정상입니다.
   - 사이드바에 `선택 조건: 0건 / 전체 150건`이 표시됩니다.
   - 본문에 `조건에 맞는 데이터가 없습니다. 조건을 넓혀 보세요.`가 표시됩니다.
   - 숫자 카드, 그래프, 표는 나오지 않습니다.
4. 지역을 하나 이상 다시 선택하면 화면이 원래대로 돌아옵니다.
